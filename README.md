# B站客户端双栏布局（评论区移到右侧，边看边刷评）

把 bilibili 视频页改成客户端式的单屏双栏：左栏播放器铺满视口高度，右栏是「简介 / 评论」选项卡面板，中间可拖拽调宽。整页不滚动，看视频和刷评论同时进行。

Tampermonkey / Violentmonkey 用户脚本，当前版本 **1.4.7**。

发布源为本仓库；Greasy Fork 上的 [598035](https://greasyfork.org/scripts/598035) 作为镜像，从本仓库同步。

## 安装

1. 先装一个用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 打开 [`bilibili-client-layout.user.js`](../../raw/main/bilibili-client-layout.user.js)，管理器会弹出安装确认页，点安装即可。

装好后更新检查直接指向本仓库的 `main` 分支，发新版即自动更新。也可以从 Greasy Fork 镜像安装。

生效页面：`www.bilibili.com/video/*` 与 `www.bilibili.com/list/*`（稍后再看、收藏夹、合集等二级播放页）。

> **从 1.4.4 及更早版本升级的用户注意**：1.4.5 把 `@namespace` 从占位值改成了真实仓库地址。
> 脚本管理器用「name + namespace」认脚本身份，namespace 变了会被当成**另一个脚本**。
> 请先在管理器里**卸载旧的那一份**，再从上面重新安装，否则两份会同时运行（双面板、双 ⇄ 按钮）。

## 功能

- **单屏双栏**：隐藏B站顶栏，播放器从屏幕最顶端开始铺满左栏；标题、简介、标签、UP主、播放列表、推荐等原本散落在页面上的信息块，全部收进右栏「简介」页签。
- **拖拽调宽**：拖动两栏之间的手柄调整右栏宽度（16%–50%，默认 25%），拖动时显示百分比气泡，双击手柄重置为默认。
- **边看边评**：评论页签独立滚动并正常翻页加载；压缩了评论区左侧的大片空白。
- **一键切回原布局**：工具条上的 ⇄ 按钮，或管理器菜单。切回时被搬走的节点精确归位。
- **滚轮调音量**：鼠标停在播放画面上滚动滚轮即可加减音量，画面中央弹出提示条。播放器全屏 / 网页全屏时不接管，交还B站自带的滚轮音量。
- **防黑屏**：钉住页面滚动位置、关闭浏览器的自动画中画开关、已经掉进小窗 / 画中画时自动拉回，避免「视频跑到右下角小窗、主播放区一片黑」。
- **全屏让路**：播放器全屏（含网页全屏）期间脚本停手，排版完全交给B站。

## 管理器菜单项

| 菜单 | 说明 |
| --- | --- |
| 切换：客户端双栏 / B站原布局 | 与 ⇄ 按钮等效 |
| 右栏宽度：重置为默认 | 回到 25% |
| 页签：默认打开「评论」/ 记住上次 | 默认每次打开视频都停在评论页签 |
| 面板滚动条：仅滑块 / 透明细条 / 隐藏 / 系统默认 | 默认「仅滑块」：自绘浮动滑块，无轨道、不占内容宽度，闲置淡出、悬停保持 |
| 滚轮调音量：开 / 关 | 默认开 |
| 滚轮调音量的步长 | 2% / 5% / 10% / 20%，默认 5% |
| 滚轮调音量时的画面中央提示：开 / 关 | 默认开 |

设置通过 `GM_setValue` 持久化。

## 已知限制

- 面向 Chromium 内核（Chrome / Edge）开发与实测，其它内核未验证。
- 脚本依赖B站前端的 DOM 结构。B站改版可能导致信息块搬移失效，需要跟着更新选择器。
- 声明了 `@grant GM_*`，因此运行在管理器的**隔离世界**里：原型层面的补丁（如拦截 `requestPictureInPicture`）对页面主世界无效，脚本一律改用 DOM 级手段。
- 与视频页保持 SPA 兼容：换视频不会重跑脚本，靠每秒一次的路由指纹 + 自愈体检维持布局。
